# BookBot

BookBot is a command-line tool that produces a neat report on character count and word count for any submitted txt file.

BookBot is my first [Boot.dev](https://www.boot.dev) project!

Features:
* Counts total words.
* Counts total characters.
* Finds the five most common words.
* Sorts the characters from most common to least common with number of appearances.
* Produces a terminal report of all this info.

Requirements:
* Python 3

Installation:
* Clone this repository: git clone https://github.com/ElliotFackler/BookBot.git
cd BookBot
* No external dependencies are required — BookBot only uses the Python standard library.

Instructions:
* You can run this program using the following command "Python3 main.py [path to book]"
