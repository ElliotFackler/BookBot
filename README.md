# BookBot

BookBot is my first [Boot.dev](https://www.boot.dev) project!

This program produces a neat report on character count and word count for any submitted book.

Frankenstein book path: books/frankenstein.txt
Instructions:
* You can run this program using the following command "Python3 main.py [path to book]"
* How to submit file: bootdev run -s

Tech Stack:
* Python3
* I run this on WSL because it's awesome, but whatever suits your fancy
